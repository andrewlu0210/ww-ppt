# Want-Point（旺-Point）

用 Rust + Tauri v2 開發的 macOS 簡報 App，目標是做到和 Microsoft PowerPoint 一樣的操作體驗。架構和階段規劃見 [ppt-plan.md](ppt-plan.md)。

目前進度：**M2 PPTX 相容**進行中（M0 技術驗證、M1 核心編輯器已完成）。

## 環境需求

- macOS 26 以上（WKWebView 需要支援 WebGPU）
- rustup 管理的 Rust stable，加上 `wasm32-unknown-unknown` target
  - Homebrew 的 rustc 沒有 wasm target，腳本會優先使用 `~/.cargo/bin`
- `wasm-bindgen-cli`，版本必須和 `crates/ppt-wasm/Cargo.toml` 一致：`cargo install wasm-bindgen-cli --version 0.2.129`
- Node.js 24 以上

## 執行

```sh
npm install
npm run wasm                       # 編譯編輯器核心 → ui/src/wasm
npm run tauri dev                  # 啟動 App
npm run tauri dev -- -- -- /絕對路徑/deck.pptx   # 啟動時直接開啟檔案
```

測試：

```sh
cargo test --workspace
# 範例簡報 samples/m0-demo.pptx 可以重新產生：
uv run --no-project --with python-pptx python scripts/make_sample_pptx.py samples/m0-demo.pptx
```

## 視覺回歸測試

`samples/vr/` 裡每份 `<名稱>.pptx` 搭配一份從 PowerPoint 匯出的 `<名稱>.pdf` 當基準。工具會逐頁渲染並和 PDF 比對，另外會把簡報存檔再開啟，確認存檔後畫面不變。需要 poppler 的 `pdftoppm`（`brew install poppler`）。

```sh
cargo run -p ppt-vr --release                 # 和 samples/vr/baseline.json 比對，有頁面退步就失敗
cargo run -p ppt-vr --release -- --update     # 修正後，把目前分數寫成新基準
cargo run -p ppt-vr --release -- --only test  # 只跑一份
```

- **分數**：不一致像素佔整頁的百分比。容許 1px 位移和反鋸齒差異，所以剩下的差異主要來自字型不同，例如微軟雅黑被替換成蘋方。
- **結果**：輸出到 `target/vr/<名稱>/`。`page-NN.png` 由左到右是基準、本程式渲染、差異（紅色）；`report.md` 是分數表。
- **私人樣本**：`samples/vr/test.*` 是真實工作簡報，已列在 `.gitignore`，不要提交。
- **匯出 PDF 的比對**：`cargo run -p ppt-vr --release --example pdf -- samples/vr/test.pptx` 會把簡報匯出成 PDF，再和 PowerPoint 的 PDF 以及螢幕渲染逐頁比較。結果在 `target/vr-pdf/<名稱>/`，`page-NN.png` 由左到右是基準、匯出的 PDF、螢幕渲染。

## 功能（M4 進行中）

- **匯出 PDF**（檔案 > 匯出為 PDF…，⌘⇧E）：
  - 每張投影片一頁，頁面大小和投影片相同；隱藏的投影片不匯出。
  - 和螢幕共用同一套繪圖程式（`Canvas` 介面：螢幕畫到 vello，匯出畫到 krilla 的 PDF 頁面），所以內容和畫面一致。
  - 圖形、線條、漸層維持向量；文字維持文字：字型以子集嵌入並帶 Unicode 對應，可以搜尋和複製。
  - 圖片直接嵌入原始的 JPEG 或 PNG，不重新壓縮。
  - 限制：陰影用幾層半透明圖形近似模糊；可變字型以預設字重嵌入。
- **尋找與取代**（編輯 > 尋找… ⌘F、取代… ⌥⌘F、尋找下一個 ⌘G、尋找上一個 ⇧⌘G）：
  - 畫布右上角的尋找列，依序搜尋每張投影片的文字方塊、圖形文字、表格儲存格和備忘稿，顯示「第幾個 / 共幾個」。Enter 下一個，⇧Enter 上一個，Esc 關閉。
  - 選項：大小寫須相符、全字拼寫須相符（中日韓文字沒有字詞邊界，不受全字限制）。
  - 找到投影片上的文字時，直接進入該文字的編輯並選取；找到備忘稿時，打開備忘稿窗格並選取。
  - 取代：取代目前選取的符合項目並找下一個，可以像打字一樣復原。全部取代：一次取代整份簡報，算一個復原步驟；取代的文字沿用原本那段文字的格式。
- **拼字檢查**（校閱 > 拼字檢查，預設開啟）：
  - 用 macOS 系統的拼字檢查（NSSpellChecker），跟著系統的語言設定和使用者字典；中文不檢查。
  - 目前投影片的文字（含表格儲存格，以及正在編輯的文字）在停止輸入片刻後檢查，錯字下畫紅色波浪線。
  - 在錯字上按右鍵：選建議字直接替換（可以復原）、忽略拼字（這次執行期間）、加入字典（存進系統字典，其他 App 也會認得）。
  - 備忘稿使用 WebKit 內建的拼字檢查。
- **常用分頁補齊**：
  - 字型：刪除線、上標、下標（縮小為 2/3 並位移，存成 `baseline`）、字元間距（非常緊到非常鬆，存成 `spc`）、清除所有格式設定（回到佔位符或母片繼承的格式，保留超連結）。
  - 段落：行距（1.0–3.0）、對齊文字（上、中、下；改寫原本 `bodyPr` 的 `anchor`，其他設定保留）。
  - 投影片：版面配置（套用到目前投影片）、重設。換版面配置時，佔位符依類型和編號對應到新版面配置的位置，沒覆寫過的格式跟著換成新的版面配置；新版面配置沒有的空白佔位符會移除，缺少的會補上。重設會把佔位符的位置和格式都還原成版面配置的。存檔時投影片改指向新的版面配置，類型改變的佔位符也會改寫 `p:ph`。
  - 編輯：尋找、取代、全選。
- **圖形格式補齊**：
  - 大小與位置：高度、寬度、水平、垂直（公分）、旋轉角度，按 Enter 或離開欄位時套用；選取群組時整組縮放。
  - 旋轉：向右／向左旋轉 90°、垂直翻轉、水平翻轉；群組以整組的中心旋轉或鏡射。
  - 變更圖案：把選取的圖案換成其他預設圖案，填滿、外框、文字保留。
  - 陰影：右下、下、右、左下位移與置中柔邊；存檔只替換 `effectLst` 裡的 `outerShdw`，其他效果保留，移除陰影會寫入空的 `effectLst`。非矩形的圖案也會畫出陰影（以柔邊近似模糊）。
  - 圖片格式（選取圖片時出現）：裁剪模式（拖曳控點裁剪，被裁掉的部分淡淡顯示，Enter 或 Esc 結束）、以百分比裁剪、重設圖片（移除裁剪、旋轉和翻轉，回到圖片原本的比例）。裁剪時圖片的縮放比例不變，存成 `srcRect`。
- **插入補齊**：
  - 圖案：完整的圖案庫（線條、矩形、基本圖案、箭號、方程式、流程圖、星星及綵帶、圖說文字，約 150 種，圖示由幾何引擎即時產生）。選好後在投影片上拖曳畫出（Shift 保持正方形，線條固定為 45° 的倍數），直接點一下則放一個預設大小的；Esc 取消。「圖形格式 > 變更圖案」也用同一個圖案庫。
  - 頁首及頁尾：日期（自動更新或固定）、投影片編號、頁尾文字，可套用到目前投影片或全部，並可略過標題投影片。佔位符取自各投影片的版面配置。
  - 欄位：讀寫 `a:fld`（投影片編號、日期等），編輯文字後存檔不會變成一般文字；畫面上投影片編號會顯示實際的頁碼。
  - 符號：常用符號、箭號、圖形、全形標點、圈號數字、希臘字母；插入到游標處，沒有在編輯文字時新增一個文字方塊。
- **設計分頁**：
  - 變化：佈景主題色彩（Office、灰階、藍色、綠色、紫羅蘭色等 15 組）與字型（Office、Arial、Georgia 等 17 組，只換西文字型，保留東亞字型）。改的是母片的佈景主題，所有引用主題色彩和字型的內容一起更新；色彩選擇器也改用簡報的主題色彩。
  - 投影片大小：寬螢幕 (16:9)、標準 (4:3)、16:10、A4 或自訂公分數。比例改變時可選「最大化」或「確保最適大小」；投影片、版面配置和母片的圖形、字級、線寬、表格依比例縮放並置中，橫跨整張投影片的圖形（背景、橫幅）會拉伸以保持滿版。
  - 背景格式：實心、漸層（線性六個方向或放射）、圖片填滿，可隱藏背景圖形、重設成版面配置的背景，或套用到全部投影片。讀檔也支援漸層、圖片和佈景主題背景樣式。
  - 變更佈景主題和投影片大小會一次重整整份簡報，可以復原。
- **檢視分頁**：
  - 投影片瀏覽：所有投影片排成格狀，拖曳排序，方向鍵移動、Delete 刪除、Enter 或按兩下回到標準檢視；縮放鈕調整縮圖大小。狀態列也能切換標準／投影片瀏覽。
  - 尺規：上方和左側，以投影片中心為 0 的公分刻度，選取的圖形範圍以白色標出。
  - 格線：依格線間距（0.1–2 公分）畫在投影片上，太密時自動放寬；可開啟「物件貼齊格線」，移動和調整大小時邊緣貼齊格線（沒有更近的智慧參考線時）。
  - 輔助線：可顯示／隱藏、新增垂直或水平輔助線；空白處拖曳輔助線可移動並顯示到中心的距離，拖出投影片即刪除。移動圖形時會貼齊輔助線。
  - 輔助線、顯示輔助線、貼齊格線和格線間距存在 `ppt/viewProps.xml`，與 PowerPoint 互通；尺規和格線的顯示是本機偏好。
- **鍵盤操作**（無障礙）：
  - F6／Shift+F6 在投影片、備忘稿、縮圖面板、Ribbon 之間切換焦點，切到的窗格會短暫加框（投影片瀏覽時在瀏覽區和 Ribbon 間切換）。
  - 投影片上：Tab／Shift+Tab 依序選取圖形（群組算一個），Enter 編輯文字或進入群組，Esc 退出群組、取消選取；方向鍵移動（開啟貼齊格線時一次一格，Shift 0.1 吋，⌘ 微調），Option+←／→ 旋轉 15°（加 Shift 1°）。
  - Ribbon：在分頁列用 ←／→ 換分頁，↓ 或 Enter 進入按鈕區；按鈕區用 ←／→ 或 Tab 移動，Esc 或 ↑ 回到分頁列，再按 Esc 回到投影片。
  - 下拉面板：用鍵盤打開時焦點移入面板，↑／↓ 或 Tab 在項目間移動（Tab 不會跑出面板），Esc 關閉並回到按鈕。
  - 縮圖面板：↑／↓、Home／End 切換投影片，⌘↑／⌘↓ 移動投影片，Delete 刪除，Enter 回到投影片，Shift+F10 開啟投影片選單。
  - 有鍵盤焦點的控制項會顯示藍色焦點框。
- **替代文字與選取窗格**（無障礙）：
  - 替代文字：「圖形格式／圖片格式 > 協助工具 > 替代文字」編輯選取物件的描述，或標示為裝飾用；存成 `cNvPr` 的 `descr` 和 PowerPoint 的 decorative 標記，互通讀寫。
  - 選取窗格：列出投影片上所有物件（最上層在前，群組成員縮排在群組下），點選選取（⌘ 加選）、眼睛圖示隱藏／顯示、全部顯示／全部隱藏、按兩下或 F2 改名、▲▼ 調整上下層。鍵盤：↑／↓ 選取、空白鍵隱藏／顯示、⌘↑／⌘↓ 移動、Esc 回到投影片；F6 也會切到窗格。
  - 隱藏的圖形（`hidden="1"`）現在會完整讀入，在窗格裡可以重新顯示；隱藏時不畫、不能點選，放映和 PDF 也不會出現。
  - 上移／下移一層會把群組當成一整塊移動，不會再把別的圖形插進群組中間。
- **VoiceOver 支援**（無障礙）：
  - 投影片內容：畫布本身對螢幕閱讀器隱藏，改由一層看不見的網頁結構呈現目前投影片——依閱讀順序（由後到前）列出物件：標題是標題層級、文字以段落與清單呈現、表格是真正的表格、圖片和圖表讀替代文字（圖表沒有時讀圖表標題）；隱藏和裝飾用的物件略過。每個元素疊在對應物件的位置，VoiceOver 游標會框出物件；按 VO-空白鍵即選取該物件。
  - 播報：換投影片（「投影片 3／4：標題，N 個物件」）、選取改變（「已選取 圖片「標誌」，替代文字：…」、群組、多選、取消選取）、進入文字編輯、用鍵盤移動或旋轉時的位置與角度、復原／取消復原；放映時播報每張投影片的標題與放映結束。
  - 標籤：縮圖和投影片瀏覽的每張投影片都帶標題（隱藏的會註明），Ribbon 的分頁內容和群組有名稱，只有圖示的按鈕有文字標籤，投影片輸入區的名稱會說明目前選取的物件。
- **檢查協助工具**（無障礙）：
  - 「校閱 > 檢查協助工具」或狀態列的「協助工具：N 個問題」開啟右側窗格，依錯誤／警告／提示分組，隨編輯即時更新。
  - 錯誤：圖片、圖表、SmartArt 缺少替代文字；投影片沒有標題。警告：投影片標題重複；文字對比不足（依 WCAG，一般文字 4.5:1、18pt 或 14pt 粗體以上 3:1；背景取圖形填滿、下方的圖形、版面配置裝飾和投影片背景，半透明會混色，背後有圖片時不檢查）；表格沒有標題列。提示：標題不是第一個被讀出、閱讀順序和畫面位置不一致。
  - 點問題會跳到該投影片並選取物件，展開後有說明和修正方式：直接輸入替代文字或標示為裝飾用、開啟表格標題列、開啟選取窗格調整順序。
- **PDF 結構標記**（無障礙）：匯出的 PDF 是 tagged PDF——每張投影片一個 Sect，標題是 H1、每個段落是 P、圖片和圖表是帶替代文字的 Figure（沒有時用圖表標題或名稱），背景、版面配置裝飾、項目符號和裝飾用物件標成 artifact；文件語言 zh-TW，標題取第一張投影片的標題。

## 功能（M3）

- **投影片放映**：
  - 開始：「投影片放映」分頁、選單，或快捷鍵。從頭播放是 ⌘⇧↩ 或 F5，從目前的投影片播放是 ⌘↩ 或 ⇧F5。
  - 畫面：視窗切到全螢幕，投影片依比例填滿並加黑邊。隱藏的投影片（`show="0"`）會跳過，直接跳頁時仍可顯示。
  - 下一頁：→ ↓ 空白鍵 Enter PageDown N、滑鼠左鍵或滾輪向下。簡報筆通常送出 PageDown／PageUp，也能使用。
  - 上一頁：← ↑ PageUp Backspace P、滑鼠右鍵或滾輪向上。
  - 跳頁：Home／End 到第一頁或最後一頁，輸入數字再按 Enter 跳到指定頁。
  - 黑屏和白屏：B 或 . 切換黑屏，W 或 , 切換白屏。
  - 結束：Esc。最後一頁之後顯示「放映結束」畫面，再按一下就結束。結束後編輯畫面停在最後放映的那一頁。
- **轉場**：
  - 支援：切換、淡出（可穿過黑色）、推入、擦去、覆蓋、揭露、分割、溶解、隨機線條、縮放、圓形。其他類型（例如轉化、漩渦）先採用檔案裡的替代寫法，沒有替代寫法就以淡出播放；存檔時原樣保留。
  - 放映時往下一張會播放轉場，觀眾視窗和簡報者檢視同步播放；轉場中再按一下會直接完成。設定「之後 N 秒」的投影片會自動前進；取消「按一下滑鼠時」後，點滑鼠不會換頁（鍵盤仍可）。
  - 「轉場」分頁：選類型（自動預覽）、效果選項、期間、換頁方式、全部套用、預覽。有轉場的投影片在縮圖編號下有 ★。
- **動畫**：
  - 讀取投影片的時間樹（`p:timing`），播放的是 PowerPoint 實際存下的動作，不依效果名稱：顯示或隱藏、數值插補（含 `#ppt_x`、`$` 等公式）、濾鏡（淡出、擦去、溶解、百葉窗、方塊、圓形、菱形、十字形、輪子、隨機線條等）、縮放、旋轉、移動路徑、變色。支援「按一下」、「與前一動畫同時」、「接續前一動畫」、延遲、加減速、重複與自動倒轉；依段落的效果會逐段顯示或淡入。
  - 放映時按下一張會先逐步播放動畫，播完才換頁；上一張會退回上一步（直接顯示完成狀態）。自動開始的效果在轉場結束後播放。觀眾視窗與簡報者檢視同步播放，簡報者檢視顯示「動畫 k / n」。
  - 「動畫」分頁：
    - 為選取的圖形（或整個群組）新增動畫：進入有出現、淡出、飛入、擦去、縮放、分割、百葉窗、方塊、圓形、輪子、隨機線條、棋盤式、溶解；強調有放大/縮小、陀螺轉；結束有消失、淡出、飛出、擦去、縮放、分割、輪子、隨機線條、溶解。同時選取多個圖形時，第一個是「按一下」，其餘「與前一動畫同時」。
    - 變更效果、效果選項（飛入、飛出、擦去的方向）、開始方式、期間、延遲；往前或往後移、移除。每項修改都可以復原。
    - 動畫清單：點一列會選取它的圖形；在畫布上選取圖形也會選到它的動畫。這個分頁開著時，畫布上的圖形旁會顯示播放順序編號。
    - 在編輯畫面預覽整頁動畫。
  - 存檔：沒改過動畫的投影片原樣保留。改過的投影片會重寫時間樹，沒改的效果沿用原本的 XML（只更新節點編號、圖形 id，以及開始方式、延遲或期間）；新效果用 PowerPoint 相同的寫法產生，並補上建置清單（`p:bldLst`）。
  - 刪除圖形會一併移除它的動畫；組成群組時，成員原有的動畫會移除（PowerPoint 只能對整個群組設定動畫）。複製投影片時，複本的動畫指向複本自己的圖形。
- **簡報者檢視與多螢幕**：
  - 接上第二個螢幕時（「投影片放映」分頁的「使用簡報者檢視」預設開啟），投影片在另一個螢幕全螢幕放映，這個螢幕顯示簡報者檢視。也可以用「簡報者檢視」按鈕或 ⌥↩ 直接開始。
  - 簡報者檢視：目前投影片、下一張預覽、備忘稿（A−／A+ 調整字級）、已經過時間（暫停、重設）、目前時刻、頁碼、上一張／下一張、黑屏、結束放映。
  - 兩個視窗都能操作，換頁會同步。觀眾視窗載入的是開始放映當下的簡報內容，包括還沒存檔的修改。
  - 只有一個螢幕時，放映中按 ⌥↩ 可在投影片和簡報者檢視之間切換。
- **備忘稿**：
  - 位置：編輯畫面下方的窗格，拖曳上緣可以調整高度。用狀態列的「備忘稿」、「檢視」分頁或「檢視 > 備忘稿」選單顯示或隱藏。
  - 編輯：以純文字編輯，一行是一個段落。在窗格裡按 ⌘Z 會復原打的字；回到投影片後按 ⌘Z，一次輸入的內容算一個復原步驟。
  - 存檔：
    - 沒改過的備忘稿原樣保留。
    - 改過的只替換文字，沿用原本的文字格式。
    - 新投影片或原本沒有備忘稿的投影片，會新增備忘稿頁面；簡報沒有備忘稿母片時也一併建立。
    - 複製的投影片會帶著備忘稿。

## 功能（M2）

- **表格**：
  - **顯示**：格線、合併儲存格、框線、填色，以及表格樣式（標題列、交錯底色）。檔案沒有定義預設樣式時，用內建的「中度樣式 2 - 輔色 1」。
  - **編輯**：點儲存格直接輸入，Tab／⇧Tab 換格（最後一格按 Tab 會新增一列）；列高會隨文字自動長高。
  - **調整**：拖曳內部格線調整欄寬、列高；拖曳外框移動表格。「表格版面配置」分頁可以插入或刪除列、欄；「插入 > 表格」用格子選擇器選大小。
  - **存檔**：只改文字或欄寬時，只改寫變動的儲存格；插入或刪除過列欄時，整個表格重新產生。
  - **多格選取**：從一格拖曳到另一格，或按住 ⇧ 點選；範圍自動擴大到完整的合併儲存格。選取後可以一次套用字型格式，Delete 清空文字。
  - **合併與分割**：合併時保留所有文字；分割成任意列數 × 欄數，格線不夠時自動補上，其他列跨過新格線。
  - **表格設計**：樣式預覽庫（中度樣式 2 的 7 種配色，加上無樣式），標題列、合計列、帶狀列、首欄、末欄、帶狀欄選項；網底、框線（全部、外框、內框、上下左右、無框線，可選色彩和寬度）、垂直對齊。
  - **樣式定義**：套用的樣式不在檔案的 `tableStyles.xml` 裡時，存檔會把定義補寫進去。
- **群組**：
  - **選取**：點一下選取整組；再點一下或雙擊進入群組，編輯個別圖形。
  - **編輯**：整組移動或縮放；⌘⌥G 組成群組，⌘⌥⇧G 取消群組。
  - **存檔**：只移動或縮放整組時，只改外層群組的位置，巢狀結構完整保留；成員改過時重建群組。
- **圖形**：
  - **預設圖形**：內建 ECMA-376 `presetShapeDefinitions.xml` 的公式引擎，支援全部 180 多種預設圖形，包含連接線、弧形、調整值和文字區域。
  - **填色**：漸層（線性、放射），以及佈景主題的填色樣式（`fillRef`）。
  - **線條**：虛線樣式和箭頭（三角形、箭號、菱形、圓形）。
  - **陰影**：矩形、圓角矩形和圖片的外陰影。
  - **群組填色**：`grpFill` 沿用群組的填色，巢狀群組也會逐層往下傳。
  - **大圖片**：長邊超過 2560 像素的圖片會先縮小，避免 GPU 圖集被佔滿後畫不出來。
- **SmartArt**：用檔案裡預先繪製的圖形顯示，存檔原樣保留。
- **圖表**：用圖表 part 裡快取的資料顯示，存檔原樣保留（還不能編輯資料）。
  - **類型**：直條或橫條（群組式、堆疊式、百分比堆疊）、折線、區域、圓形、立體圓形、環圈圖，以及組合圖和副座標軸。
  - **版面**：手動版面配置、仿 Excel 的自動刻度、格線、類別標籤（太擠時會旋轉並間隔顯示）、圖例。
  - **資料標籤**：位置、數字格式、自訂文字、個別標籤的位移。
- **文字**：
  - **編號清單**：1. 2. 3.、I. II.、a)、①②③、一. 二. 等，提供編號格式選單。
  - **項目符號**：可以有自己的字型、顏色、大小；Wingdings 等符號字型會換成對應的 Unicode 字元。
  - **超連結**：存檔保留，⌘K 新增或移除；連結文字以佈景主題的超連結色加底線顯示。
- **其他**：
  - 圖片裁切，以及依形狀外框遮罩。
  - 簡報裡有 emoji 時，才載入 Apple Color Emoji 字型；Apple Symbols 和 Zapf Dingbats 作為符號的備用字型。

## 功能（M1）

- **開啟與儲存 PPTX**：沒改過的投影片原樣保留；改過的投影片只重寫有變動的圖形，而且只寫和母片繼承不同的屬性。圖表、SmartArt 等尚不支援的物件會原樣保留。
- **新增簡報**：內建 16:9 Office 佈景主題範本，含 6 種版面配置。
- **富文字**：逐字設定字型、大小、粗斜體、底線、顏色；段落對齊、項目符號、清單階層（Tab／⇧Tab）、行距。支援注音等 IME 組字；文字框內 ⌘Z 會先復原打字。
- **圖形**：
  - 新增圖形、圖片、文字方塊；填滿、外框顏色和寬度。
  - 多選（⇧ 點按）、框選、智慧參考線（按住 ⌥ 暫時關閉）。
  - 複製貼上、⌘D 複製、圖層順序、對齊。
- **投影片**：依版面配置新增、複製、刪除、拖曳排序；左側為即時縮圖；空白佔位符會顯示提示文字。
- **其他**：未儲存提醒（開新檔、開啟、關閉視窗時）。

## 結構

| 路徑 | 內容 |
|---|---|
| `crates/ppt-model` | 文件模型（EMU 座標、文字段落與樣式、表格與表格樣式） |
| `crates/ppt-ooxml` | PPTX 匯入與儲存、內建範本：佈景主題、佔位符繼承、文字樣式鏈、群組、圖片、表格 |
| `crates/ppt-geometry` | 預設圖形公式引擎（`presets.xml` 取自 Apache POI，Apache 2.0）、自訂幾何、文字區域、座標轉換 |
| `crates/ppt-text` | 字型註冊、字型替代；整個文字框一個 parley 排版，逐行套用段落縮排與對齊 |
| `crates/ppt-render` | 繪製投影片（透過 `Canvas` 介面，螢幕用 vello）、選取框、文字游標 |
| `crates/ppt-pdf` | 匯出 PDF：用 krilla 實作 `Canvas`，文字嵌入字型子集 |
| `crates/ppt-editor` | 選取、多選、參考線、縮放、旋轉、富文字編輯（`richedit.rs`）、IME、格式、投影片操作、復原 |
| `crates/ppt-wasm` | 給前端呼叫的 WASM 介面，包含 WebGPU 繪製流程 |
| `crates/ppt-fonts` | 原生字型服務：用 fontique 找系統字型檔，加上 Office 字型替代表（App 和測試共用） |
| `crates/ppt-vr` | 視覺回歸測試：用原生 wgpu 離線渲染投影片，和 PowerPoint 匯出的 PDF 比對 |
| `src-tauri` | 原生後端：讀檔、字型服務、選單 |
| `ui` | React 外框：Ribbon、投影片清單、畫布、IME 輸入橋接 |

## 開發用自動化

設定 `WW_PPT_AUTOMATION=<資料夾>` 啟動後，App 會讀取 `<資料夾>/commands.txt`，每行一個指令，例如 `click 400 300 2`、`drag x1 y1 x2 y2`、`down`/`move`/`up`、`text 你好`、`compose ㄋㄧˇ`、`commit 你`、`key Escape`、`run {"kind":"newSlide"}`、`save 路徑`、`shot 名稱`、`thumbs 名稱`。執行結果寫到 `log.txt`，畫布截圖存成 `名稱.png`。實作見 `ui/src/lib/automation.ts`。

存檔的開發工具：`cargo run -p ppt-ooxml --example resave -- in.pptx out.pptx [--edit]`（`in.pptx` 可用 `template` 代表內建範本）。
